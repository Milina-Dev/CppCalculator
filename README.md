# CppCalculator

Консольный калькулятор для выполнения арифметических операций над двумя целыми числами.

## Описание проекта

Программа позволяет выполнять основные арифметические операции, изменять значения выбранных переменных и проверять результаты вычислений на переполнение.

## Возможности программы

- Сложение ("+").
- Вычитание ("-").
- Умножение ("*").
- Деление ("/").
- Увеличение выбранной переменной на единицу ("++").
- Уменьшение выбранной переменной на единицу ("--").
- Проверка деления на ноль.
- Проверка переполнения целочисленных операций.
- Выход из программы по команде "exit".

## Алгоритм работы программы

1. Пользователь вводит арифметическую операцию или команду выхода.
2. При выборе операции пользователь вводит два целых числа.
3. Программа выполняет выбранное действие: сложение, вычитание, умножение или деление.
4. При выборе увеличения или уменьшения пользователь указывает, какое число необходимо изменить.
5. Перед выполнением вычислений программа проверяет возможность переполнения и деления на ноль.
6. Результат вычисления или сообщение об ошибке выводится на экран.
7. Работа программы повторяется до ввода команды "exit".

## Запуск программы

Откройте файл решения проекта в Visual Studio, соберите проект и запустите программу.
